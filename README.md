**WHATSAPP**
1. Hardware: Smartphones, PC, Tablets,  some smartwatches, Mic, Speaker 
2. Software: WA messenger and business, Windows, iOS, macOD, Android
3. Data: phone number, name, profile photo, messages, images, videos, docs, status
4. People: friends and families, businesses, engineers, owner Mark Z
5. Process: 
            *Register your account
            *Verify your numbers
            *login and create messages
            *messages go from your whatsapp to the server
            *server stores the message as data
            *the receiver can see the message and can reply*
            
**Raw Data**
1. location when you share it with your contacts

**Transforming Data**
When you share your location, the system picks up information on where you are and shows the person receiving you live location a map that can be used by them to check how far you are when they open the location using google maps.
